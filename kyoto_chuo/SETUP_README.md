# 京都中央店版 セットアップ手順

このフォルダ（`kyoto_chuo/`）は、神戸中央店版メンテナンスアプリを京都中央店専用に
複製した、完全に独立したシステム一式です。スプレッドシート3枚とコードは
すでに新規コピー済みですが、**GAS（Google Apps Script）Webアプリのデプロイと、
ログイン情報の登録だけは、Google側の操作が必要なため、ご自身で行ってください。**

| 業務データ・印刷用・連絡コメント | 【京都中央店】業務データ・印刷用・連絡コメント | `16oxBVjnVefhpuPiodpH8jWzjjZ3Vp_tFbcOkpizU5zk` |

## 2. GAS Webアプリの新規デプロイ（ここだけ手動操作が必要です）

書き込み系の操作（申請・承認・差戻しなど）はすべて、1つのGAS Webアプリ経由で
スプレッドシートに書き込まれます。神戸中央店版のGAS Webアプリをそのまま使うと、
京都中央店のデータが神戸中央店側のGASプロジェクトの権限で処理されてしまうため、
**京都中央店専用のGASプロジェクトを新規に作成・デプロイしてください。**

### 手順

1. 上記3つの新しいスプレッドシートのいずれか（どれでも構いません。例えば
   「【京都中央店】マスタデータ」）を開く。
2. メニューから **拡張機能 → Apps Script** を選択し、新しいApps Scriptプロジェクトを開く。
3. デフォルトで生成される `コード.gs`（または `Code.gs`）の内容を全て削除し、
   このリポジトリの `kyoto_chuo/gas_doPost.js` の内容を全てコピー＆ペーストする。
   （このファイルはすでに3つの新しいスプレッドシートIDを参照するよう書き換え済みです。）
4. 画面右上の **デプロイ → 新しいデプロイ** をクリック。
5. 「種類の選択」で **ウェブアプリ** を選択。
6. 設定は神戸中央店版のGASデプロイと同じにしてください（通常は以下の想定）：
   - 実行ユーザー：**自分（Me）**
   - アクセスできるユーザー：**全員**（アプリがログイン認証なしでPOSTできる必要があるため）
7. **デプロイ** をクリックし、Googleの権限承認（自分のGoogleアカウントでの承認）を行う。
8. デプロイ完了後に表示される **ウェブアプリのURL**（`https://script.google.com/macros/s/XXXXXXXX/exec` の形式）をコピーする。

### URLをコードに反映する

`kyoto_chuo/views/maint_common.py` を開き、以下の行を探してください。

```python
GAS_URL = "★★ここに京都中央店用GAS WebアプリのURLを貼り付けてください（例: https://script.google.com/macros/s/XXXXXXXX/exec）★★"
```

この `"★★...★★"` の部分を、手順8で取得した実際のURLに置き換えてください。例：

```python
GAS_URL = "https://script.google.com/macros/s/AKfycbxXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXX/exec"
```

**この置き換えが完了するまで、京都中央店版アプリは申請・承認・差戻しなどの
書き込み操作が一切できません。**（閲覧は可能ですが、保存時にエラーになります。）

## 3. ログイン情報の登録（手動で1行以上の追加が必要です）

新しい「マスタデータ」スプレッドシートの「ログイン情報」シートは、表題行のみで
データ行は空です。京都中央店の担当者が実際にログインできるよう、最低1行、
ログイン情報を追加してください（列構成：メールアドレス／拠点／担当者名／パスワード／URL／権限／エリア）。

参考：神戸中央店版の元のマスタデータには、京都中央店用と思われる仮の行
（`shuttle.kyouto.chuouten@gmail.com` / パスワード `6666`）が既に存在していました。
これをそのまま使うか、新しいアカウント情報に差し替えるかは運用側でご判断ください
（今回は元データに影響を与えないよう、このアカウントを新しいシートへ自動転記することはしていません）。

## 4. デプロイ先について

`kyoto_chuo/` はStreamlitアプリとして、神戸中央店版と同じ方法で
（例：Streamlit CloudやサーバーでNewのURL/ポートとして）別途デプロイしてください。
神戸中央店版と同じGitリポジトリ内の別フォルダなので、デプロイ時のエントリーポイントを
`kyoto_chuo/app.py` に指定すれば、神戸中央店版とは完全に独立したURLで動作します。
